# Refleksi
1. Kapan native lebih tepat dipilih daripada cross-platform?
Jawab: Native lebih baik dipilih ketika aplikasi membutuhkan performa tinggi seperti game atau edit video, atau perlu akses ke fitur hardware terbaru yang belum didukung cross-platform. Selain itu, jika aplikasi harus mengikuti desain khusus iOS atau Android secara sempurna, atau untuk proyek jangka panjang dengan tim yang sudah ahli di platform tertentu, native lebih tepat meskipun biayanya lebih mahal.

2. Bagaimana perubahan state berhubungan dengan widget tree dan UI deklaratif?
Jawab:Di Flutter, state berubah maka widget tree akan dibangun ulang. Karena menggunakan UI deklaratif, kita hanya perlu mendeskripsikan tampilan berdasarkan state, dan framework akan otomatis update bagian yang berubah. Jadi kita tidak perlu repot mengatur UI secara manual, cukup ubah state maka tampilan akan mengikuti dengan sendirinya.
  
3. Mengapa commit kecil dengan pesan jelas bermanfaat bagi pekerjaan tim dan portfolio?
Jawab:Commit kecil memudahkan tim saat code review karena perubahan lebih mudah dipahami, dan jika ada bug kita bisa langsung tahu penyebabnya. Untuk portfolio, commit yang rapi menunjukkan kita profesional dan terorganisir dalam bekerja, sehingga calon employer bisa melihat kualitas kerja kita dari cara kita mengelola kode.
