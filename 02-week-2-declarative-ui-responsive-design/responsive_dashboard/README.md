# Refleksi 
1. Apa perbedaan cara berpikir imperative dan declarative saat membangun UI?
   Jawab: Pada pendekatan Imperative secara detail langkah-langkah yang harus dilakukan untuk mengubah tampilan UI yaitu dengan menambahkan komponen, mengubah teks, atau memperbarui posisi suatu elemen. Sedangkan pada pendekatan Declarative cukup mendeskripsikan kondisi atau bentuk UI yang diinginkan berdasarkan statu saat ini.
   
3. Kapan Expanded membantu dan kapan penggunaannya justru menghasilkan layout error?
   Jawab:Expanded membantu ketika digunakan dalam row, column, atau flex untuk membuat sebuah widget mengisi ruang yang tersedia secara fleksibel.
   
5. Bagaimana breakpoint dan theme memengaruhi pengalaman pengguna?
   Jawab: Breakpoint menentukan bagaimana tampilan aplikasi menyesuaikan ukuran layar pada layar kecil, misalnya tampilan dapat menggunakan satu kolom agar informasi tetap mudah dibaca, sedangkan padqa layar yang lebih lebar dapat menggunakan 2 kolom untuk memanfaatkan ruang yang tersedia.
   
7. Apa yang Anda verifikasi dari rekomendasi AI setelah tugas inti selesai?
   Jawab: Setelah saya menggunakan rekomendasi AI saya menjalankan program nya dan memastikan tidak error. saya juga memeriksa apakah responsive layout, breakpoint, penggunaan Expanded, ternyata fitur light mode dan dark mode berjalan sesuai kebutuhan.
